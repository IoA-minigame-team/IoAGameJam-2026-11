# スコアと記録

担当はC(増永)。一振りでまとめて落とすほど点が跳ね上がる計算にし、「もっと長い線で、もっと多く」を動機にする。

## 決まっていること

- **得点は落ちた時点で加算する:** 当てた時点ではない
- **一振りの得点は落とした数の2乗に比例する:** まとめて落とすほど有利になる
- **一振りとして数える範囲:** 斬り戻しから一定時間内に、同じ一振りIDで落ちた敵。玉突きで落ちた敵も含める
- **連鎖倍率:** 空振りせずに続けるほど倍率が上がり、上限がある
- **一振り最多を主要な記録にする:** リザルトで最も大きく表示し、数に応じて称号を出す

| 一振り最多 | 称号(仮) |
| --- | --- |
| 1〜4体 | 素振り |
| 5〜9体 | 一閃 |
| 10〜19体 | 断ち |
| 20体以上 | 一刀 |
