# 銘

担当はC(増永)で、抽選から選択画面、効果の適用までを通しで持つ。必達は小銘4種と大銘2種で、下の表から選ぶ。

## 決まっていること

1. 場外に落とした数が一定に達するたび、ゲームが止まり小銘の候補が3つ出る
2. ウェーブをクリアしたとき、大銘の候補が3つ出る。「今の大銘を残す」も選べる
3. 選んだらすぐに戦闘へ戻る

- **小銘は重ねられる:** 同じ小銘は最大3段階、代償つきは1回まで。重ねがけは足し算で、能力ごとに全体の上限を設ける
- **大銘はひとつだけ:** 新しく刻むと前の大銘は消える。刻んだ大銘は刀の光り方で見分けられる
- **効果は1行で説明できるものに限る**
- **各担当は銘の倍率だけを読む:** 小銘の合計を上限で切った倍率を増永が渡す。髙橋と三條は基本値だけを持ち、倍率を掛けて使う

### 小銘(各最大3段階)

| 銘 | 1段階ごとの効果 |
| --- | --- |
| 大断 | 線の幅が広がる |
| 剛力 | 吹き飛ばし力が上がる |
| 疾風 | 手ぶらの移動速度が上がる |
| 長夜 | 自動で斬り戻すまでの時間が延びる |
| 鋭光 | 光の蓄積が増える |
| 迅刃 | 斬り抜ける速さが上がる |
| 囮 | 灯喰らいの引き寄せ範囲が広がる |

### 代償つきの小銘(各1回まで、できれば)

| 銘 | 効果 |
| --- | --- |
| 重刀 | 吹き飛ばし力が大きく上がり、手ぶらの移動速度が下がる |
| 細身 | 吹き飛ばし力が上がり、線の幅が狭まる |
| 捨て身 | 吹き飛ばし力が上がり、被弾の上限が1減る |

### 大銘(ひとつだけ)

| 銘 | 効果 |
| --- | --- |
| 残光 | 斬り抜けた線がしばらく残り、触れた敵を押し出す |
| 返し | 斬り抜けた直後、同じ線を逆向きにもう一度斬り抜ける |
| 震 | 斬り抜けて止まった瞬間、自分の周りの敵を外へ押し出す |
| 引力 | 刀を刺した瞬間、周りの敵を刀へ引き寄せる |

「返し」は斬り戻しそのものの変化なので髙橋が実装する。「震」「引力」「残光」は増永がイベントを受けて動く独立した処理として作り、吹き飛ばしは ILaunchable を使う。引力で敵を動かす方法は三條と相談する。

## 任せること

- 必達の小銘4種と大銘2種をどれにするか(増永が髙橋と相談して決める。「返し」と増永の1種にすると負荷が偏らない)
- 各段階の上がり幅と、候補の抽選の重み(増永)
- 大銘の効果の具体的な動き(増永。「返し」は髙橋)
- 銘の正式な名前と説明文(増永)
