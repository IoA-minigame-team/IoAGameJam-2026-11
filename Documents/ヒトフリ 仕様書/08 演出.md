# 演出

主人公の体で起きる演出はA(髙橋)、敵側と世界側の演出と演出の道具はC(増永)が持つ。下の表は「何を伝えるか」を揃えるためのもので、作り方は担当に任せる。

## 段階ごとの演出

| 段階 | 伝えること | 担当 | 必達の演出 |
| --- | --- | --- | --- |
| 置く | ここから斬り戻す。手ぶらになった | A | 刺さる音、光の輪、主人公のアクセントが消えて白黒になる |
| 走る | 心細さと、線が伸びる期待 | A | 線が自分に追従する |
| 斬り抜ける | 群れを斬り抜ける爽快感 | A | 残像と光の軌跡、引き抜いた瞬間に色が戻る |
| 当たる | 手応えと、飛ぶ向き | A | 短いヒットストップ、敵が白く光る |
| 飛ぶ | 当たった位置で向きが変わる面白さ | C | 速さに応じた残光 |
| 縁を越える | 落とした瞬間 | C | 「抜けた」と分かる効果音 |
| 落ちる | 群れごと落とす達成感 | C | 霧の中で光の粒になって消える |
| 納刀 | 一振りの締めくくり | A | 納刀音と小さなヒットストップ |
| 踏みとどまる | 惜しさ | C | 縁で揺れる |
| 空振り | 失敗 | A | 鈍い音と重い硬直 |

大量撃破時の色反転と、被弾部位が赤く染まる表現は「できれば」。

## 斬り抜け演出(定点カメラ)

担当はA(髙橋)。線上の敵が多い一振りだけ、斬り終わる地点の斜め側に置いた定点カメラへ切り替える。

### 決まっていること

- **発動条件:** 離した瞬間に確定する線上の敵が5体以上(仮)。クールダウンは設けず、多すぎればしきい値で調整する
- **流れ:** 離した瞬間にスロー → 定点カメラへハードカット → 主人公が駆け込んで止まり、群れが飛んでいく → 納刀後に見下ろしへ短いブレンドで戻る
- **配置の基準は崖ではなく終点:** ステージの形に依存しないよう、斬り抜ける向きと終点から位置を決める。駆け込む主人公と止まる瞬間の両方を収める
- **理不尽にしない:** 演出中は世界全体をスローにし、見下ろしへ戻った直後にも短い無敵を入れる

### 任せること(髙橋)

- 定点カメラの距離、高さ、左右、見る位置
- 肩越しカメラ(できれば)を挟むかどうか
- 敵がカメラに被る場合の対策(ディザ半透明化は余裕があれば)

## 時間制御

ヒットストップ、演出のスロー、銘の選択中の停止はどれも Time.timeScale を使うので、仕組みはA(髙橋)が1か所にまとめ、他の担当は要求を出すだけにする。優先度は「銘の選択中の停止 > ヒットストップ > スロー」。UIとカメラはスロー中も動くようにする。
