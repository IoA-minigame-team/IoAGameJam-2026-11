# パラメータ

すべて仮の値で、担当が自由に調整してよい。値は担当ごとのScriptableObjectに置き、プレイ中でもインスペクターから変えられるようにする。良い値が見つかったらこの表も更新する。

| パラメータ | 初期値 | 置き場 |
| --- | --- | --- |
| 突き立てる瞬間の隙 | 0.1秒 | PlayerTuning |
| 手ぶらの移動速度 | 通常の1.3倍 | PlayerTuning |
| 斬り戻しの所要時間 | 0.2秒(瞬間移動と斬り抜けを含む、この間は無敵) | PlayerTuning |
| 斬り戻し後の硬直 | 命中時0.1秒、空振り時0.6秒 | PlayerTuning |
| 線の幅 | 1.2m | PlayerTuning |
| 基本の吹き飛ばし力 | 6m/s | PlayerTuning |
| 線の長さの係数 | 線1mごとに+10% | PlayerTuning |
| 横方向への逸れ | 線の端で当たると斬り抜ける向きから90度 | PlayerTuning |
| 被弾の上限 | 3回 | PlayerTuning |
| 斬り抜け演出の発動しきい値 | 線上の敵5体以上 | PlayerTuning |
| 見下ろしへ戻るブレンド | 0.3秒前後 | PlayerTuning |
| 演出中のスロー倍率、演出後の無敵 | テストで決める | PlayerTuning |
| 自動で斬り戻すまでの時間 | 3秒(灯喰らい1体ごとに0.3秒短縮、下限1秒) | PlayerTuning |
| 大銘「返し」で逆向きに斬り抜け始めるまでの間 | 0秒(この間も無敵) | PlayerTuning |
| 灯喰らいの引き寄せ範囲 | 刀から半径10m | EnemyTuning |
| 光の蓄積 | 1回ごとに吹き飛びやすさ+30%(上限+150%) | EnemyTuning |
| 盾持ちの重さ | 吹き飛ばし力0.6倍 | EnemyTuning |
| 小銘の候補が出る間隔 | 場外に落とした数15体ごと | MeiTuning |
| 能力ごとの全体上限 | 線の幅は最大2倍、吹き飛ばし力は最大2.5倍 | MeiTuning |
| ヒットストップ | 0.05秒 + 当たった1体ごと0.01秒(上限0.25秒) | PlayerTuning |
| 一振りとして数える時間 | 斬り戻しから3秒以内 | FeedbackTuning |
| 一振りの得点 | 10 × 落とした数 × 落とした数 | FeedbackTuning |
| 連鎖倍率 | 1連鎖ごとに+0.1倍(上限2倍) | FeedbackTuning |

置き場の担当は、PlayerTuning が髙橋、EnemyTuning が三條、FeedbackTuning と MeiTuning が増永。小銘の段階ごとの上がり幅は増永がこの表に追記する。
