# 使い方と用語

この仕様書は、各担当が迷わず作れるだけの線引きを置く場所で、作り方までは決めない。目指す体験は『ヒトフリ』企画書、担当間の受け渡しは『ヒトフリ』チーム連携ガイドを見る。

| 担当 | 人 |
| --- | --- |
| A プレイヤー | 髙橋(カピ) |
| B 敵とゲーム進行 | 三條 |
| C 演出基盤とUI | 増永 |

## 読み方

各タブは同じ3つの見出しでできている。

- **決まっていること:** 遊びの根幹か、他の担当に影響するルール。変えたいときは朝会か夜の試遊で相談し、変更履歴に1行残す
- **任せること:** 担当が自分の判断で決めてよい部分。試してみて良かった方を採用し、結果だけ共有すればよい
- **初期値:** 数値はすべて仮で、パラメータタブにまとめてある。調整は担当が自由に行う

書かれていないことは担当の裁量とする。迷ったら「企画書の気持ちよさの方針に沿うか」で判断し、それでも迷えば相談する。

## 用語集

| 用語 | 意味 |
| --- | --- |
| 突き立て | ボタンを押してその場に刀を置くこと |
| 手ぶら | 刀を置いてからボタンを離すまでの状態 |
| 斬り戻し | ボタンを離したとき、刀の位置へ瞬間移動して離した地点まで一直線に斬り抜ける一連の動き |
| 線 | 刀と主人公を結ぶ攻撃範囲。離した瞬間に確定する |
| 一振り | 1回の斬り戻しと、それで落ちた敵のまとまり。一振りIDで数える |
| 正面度 | 線の中心軸に近いほど1、幅の端ほど0になる値 |
| 光の蓄積 | 当たるたびに敵が白く光り、吹き飛びやすくなる仕組み |
| 場外 | 敵が島の縁から落ちること。敵を倒す唯一の方法 |
| 連鎖 | 空振りせずに斬り戻しを続けること |
| 影 / 灯喰らい / 盾持ち | 敵3種の仮名(敵とウェーブを参照) |
| 小銘 / 大銘 | 重ねられる数値強化 / ひとつだけ刻める挙動の変化 |
| 斬り抜け演出 | 条件を満たした一振りだけ定点カメラに切り替える演出 |
