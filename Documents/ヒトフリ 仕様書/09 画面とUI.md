# 画面とUI

担当はC(増永)。画面は3シーンで、銘の選択はゲーム中に重ねて出す。シーンファイルは TitleScene と ResultScene を増永、GameScene を三條が持つ。

## 決まっていること

| 画面 | シーン | 必ず置くもの |
| --- | --- | --- |
| タイトル | TitleScene | タイトル、開始、操作説明(移動とボタン1つ) |
| ゲーム | GameScene | スコア、連鎖倍率、ウェーブ数。体力ゲージは出さない |
| 銘の選択 | GameScene上に重ねる | 候補3つと1行の説明。大銘では「今の大銘を残す」も選べる |
| リザルト | ResultScene | 一振り最多と称号を最も大きく、スコア、リトライ、タイトルへ |

- **ゲーム中のUIは最小限:** 情報は刀の光や主人公の色など、できるだけ画面の中で伝える
- **銘の選択はゲームパッドとマウスの両方で選べる**
- **UIはスローや停止の影響を受けない**

## 任せること(増永)

- レイアウト、フォント、画面切り替えの演出
- 操作説明の見せ方(タイトルに置くか、最初のウェーブ中に出すか)
- 次のウェーブの敵の表示(できれば)
