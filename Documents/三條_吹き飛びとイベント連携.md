# 吹き飛び処理・姿勢・イベント連携

対象プロジェクトは `C:/Users/sanjo/Ioa/gamejam/IoAGameJam-2026-11` です。既存の3体の浮遊Prefabに、ILaunchableの実装とイベントで連動する吹き飛び姿勢を追加しました。

## 画面で確認する

Unityの `Hitofuri > Sanjo > Open Enemy Launch Test` を選ぶか、`Assets/_Project/Scenes/Dev/Sanjo/EnemyLaunchTest.unity` を開き、GameタブでScaleを1xにしてPlayを押します。

| ボタン | 起きること |
| --- | --- |
| `Launch (stop)` | 3体が腕を広げて少し浮き、初速で滑って摩擦で止まる。盾持ちは同じ攻撃でも短い距離で止まる |
| `Hit again / glow` | 同じ個体へ次の一振りを通知する。光が蓄積し、次回の吹き飛びやすさが上がる |
| `Teeter at edge` | 縁の近くで止まり、バランスを取る。EnemyTeeteredを通知して通常へ戻る |
| `Launch over edge` | 足場の外へ吹き飛び、自前の重力で落下する。EnemyFellに元のslashIdを渡して個体を破棄する |
| `GameOver event test` | 共有のPlayerDamaged(0)を発行し、既存のGameOver経路で移動と姿勢を止める |
| `Reset test` | 敵を元の位置へ戻し、落下済みならPrefabから再生成する |

このシーンの長方形は軌道と縁を見やすくするための確認用の足場です。本番の黒い草原Prefabは変更していません。黒い草原のMeshColliderでも足場を認識できることは別途Playモードで検証しています。

## 処理の流れ

```text
呼出し側
  ILaunchable.IsShieldFacing(slashDir)で盾の正面を確認
  ILaunchable.WeightとGlowMultiplierを含めて初速を計算
  ILaunchable.Launch(velocity, slashId)
      ↓
Enemy（移動・状態・光・slashIdを所有）
  EnemyMotionEvents.RaiseLaunched(this, velocity)
  GameEvents.RaiseGlowChanged(this, ratio)
      ↓
EnemyActionAnimation（イベント購読。自分が対象のときだけ見た目を動かす）
  腕を広げる、移動方向へ傾く、少し跳ねる
      ↓
摩擦で停止 → 通常へ復帰
縁で停止 → GameEvents.RaiseEnemyTeetered(this) → バランスを取る
足場を失う → 落下姿勢 → GameEvents.RaiseEnemyFell(EnemyFellInfo)
```

敵本体はEnemyActionAnimationを参照しません。再生側も具体的なEnemyクラスを参照せず、ILaunchableとイベントだけで通知の対象を見分けます。他の敵の通知で一斉に動かないよう、対象を照合してから反応します。

## 共有イベントと担当内イベント

画像で指定されたC#標準のeventとRaiseメソッドの形式に合わせています。

| 通知 | 定義する場所 | 今回の用途 |
| --- | --- | --- |
| `GameEvents.GlowChanged` | 既存のShared。変更なし | 当たった個体の光の蓄積を通知 |
| `GameEvents.EnemyTeetered` | 既存のShared。変更なし | 縁で止まった個体を通知 |
| `GameEvents.EnemyFell` | 既存のShared。変更なし | 落下時にslashIdと実際の位置を通知 |
| `GameEvents.GameOver` | 既存のShared。変更なし | Enemyと再生側がそれぞれ自分の処理を停止 |
| `EnemyMotionEvents.Launched` | `Scripts/Enemy/EnemyMotionEvents.cs` | 吹き飛び開始と初速 |
| `EnemyMotionEvents.MotionUpdated` | 同上 | 速度更新。再生側で移動計算を重ねず、実際の速度で傾きを変える |
| `EnemyMotionEvents.Falling` | 同上 | 足場を失い、落下姿勢へ移る |
| `EnemyMotionEvents.Recovered` | 同上 | 地面で止まる／踏みとどまりが終わる |
| `EnemyMotionEvents.Reset` | 同上 | 再利用時に見た目を初期化 |

Sharedは他担当の所有なので変更していません。既存のGameEventsにまだない姿勢通知だけを、B担当のEnemyMotionEventsに置きました。既存の共有イベントを置き換えるものではありません。イベント購読はOnEnable、解除はOnDisableで行います。担当内イベントも購読先ごとに例外を受け止めます。

SwarmCountChanged、WaveStarted、WaveClearedは今回の吹き飛び処理には発行する場面がなく、追加実装していません。

## 受け取り側の書き方

```csharp
ILaunchable target;

void Awake() => target = GetComponent<ILaunchable>();
void OnEnable() => EnemyMotionEvents.Launched += OnLaunched;
void OnDisable() => EnemyMotionEvents.Launched -= OnLaunched;

void OnLaunched(ILaunchable enemy, Vector3 velocity)
{
    if (!ReferenceEquals(enemy, target)) return;
    // 自分の担当する見た目をここで更新する
}
```

落下を受け取る担当は既存の口をそのまま使えます。

```csharp
void OnEnable() => GameEvents.EnemyFell += OnEnemyFell;
void OnDisable() => GameEvents.EnemyFell -= OnEnemyFell;
void OnEnemyFell(EnemyFellInfo info)
{
    // info.SlashIdで一振りを集計し、info.Positionで落下演出などを出す
}
```

## 呼び出す側の注意

本番のSlashResolverはすでに `Weight` と `GlowMultiplier` を初速へ掛けています。Enemy.Launch内では再度掛けません。盾のWeightはkgではなく吹き飛ばし力の倍率で、仕様どおり0.6です。盾の正面判定はSlashResolverが先に呼びます。Launchは、その確認と初速計算が済んだものを受け取る口です。

初速の水平方向は受け取ったまま使います。現在の共有仕様が水平初速のため、Y成分は0にします。見た目だけの跳ねはReactionPivot、場外に落ちてからの重力はEnemyのRootが持ちます。AnimatorのRoot MotionとRigidbodyの力は使いません。

slashIdは停止しても消しません。次のLaunchで受け取った番号へ更新し、落下が確定したらその番号をEnemyFellInfoへ入れます。場外に出た後は落下を確定し、地面へ戻して再開する処理はしません。

吹き飛び・落下中は接触用Colliderを無効にします。この間はプレイヤーのOverlap判定による追撃対象にもなりません。地面で止まると元のCollider状態へ戻します。これは既存のPlayerTestEnemyと同じ前提です。

## 調整と再利用

EnemyTuningアセットで、摩擦、足場Rayの深さ、縁の先を調べる距離、踏みとどまり時間、落下重力、姿勢の傾きと跳ねの高さを変更できます。光は仕様の初期値で、1回0.3にMeiStats.GlowGainMultiplierを掛け、最大1.5まで蓄積します。GlowMultiplierは1〜2.5、GlowChangedへ渡す割合は0〜1です。

各PrefabのEnemyのGround Maskは、現在の黒い草原に合わせてDefaultです。床は非Trigger Colliderにしてください。床以外の物を同じレイヤーに置いた場合も足場として判定されるため、地形レイヤーをチームで分けた場合はGround Maskも合わせてください。

ラウンド再開側はGameOverController.ResetRoundを行った後、各Enemy.ResetStateを呼びます。Enemyは自分の状態だけを初期化し、ResetとGlowChangedを通知して見た目を戻します。HP、スコア、入力の初期化はそれぞれの担当が所有します。

追跡AI、攻撃ダメージ、刀への群がり、ウェーブは今回の追加範囲に含めていません。三体ともILaunchableとして外部から吹き飛ばせる状態です。
