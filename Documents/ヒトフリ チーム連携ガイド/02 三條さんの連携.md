# 三條さんの連携

三條さんの担当(敵、ウェーブ、ステージ、GameScene)のうち、他の2人と関わる所だけをまとめた。

## 受け取るもの

| いつ | 誰から | どう届くか | やること |
| --- | --- | --- | --- |
| 主人公の線が敵に当たった | 髙橋 | 敵の `Launch(velocity, slashId)` が呼ばれる | その初速で吹き飛びを始める。slashId は落ちるまで持たせる |
| 刀が刺さった | 髙橋 | `GameEvents.SwordPlanted` | 灯喰らいの目標を刀の位置に切り替える |
| 刀を引き抜いた | 髙橋 | `GameEvents.SlashStarted` | 灯喰らいの目標を主人公に戻す |
| 主人公が被弾した | 髙橋 | `GameEvents.PlayerDamaged` | 残りが0ならゲームオーバーを流す |
| 銘の効果 | 増永 | `GameContext.MeiStats` | 蓄積量と引き寄せ範囲の倍率を、使うたびに読む |
| 大銘「引力」 | 増永 | 相談して決める | 敵を刀へ引き寄せる動かし方を用意する |

## 渡すもの

| いつ | 流すイベント | 主な受け手 |
| --- | --- | --- |
| 光の蓄積が変わった | `GlowChanged` | 増永(白く光る) |
| 縁で踏みとどまった | `EnemyTeetered` | 増永(縁で揺れる) |
| 敵が場外に落ちた | `EnemyFell` | 増永(スコア、光の粒、銘のカウント) |
| 刀に群がる数が変わった | `SwarmCountChanged` | 髙橋(自動の斬り戻し)、増永(光の揺らぎ) |
| ウェーブの開始と終了 | `WaveStarted`、`WaveCleared` | 増永(表示、大銘の候補) |
| ゲームオーバー | `GameOver` | 髙橋(入力停止)、増永(リザルト) |

## 気をつけること

- **敵は `ILaunchable` を実装する:** 髙橋は敵の種類を知らず、このインターフェースだけで吹き飛ばす。盾持ちも同じ口で、正面かどうかは `IsShieldFacing` で答える
- **slashId をなくさない:** `Launch` で受け取った slashId を、落ちるまで敵に持たせて `EnemyFell` に入れる。増永さんの「一振り最多」はこの番号で数える
- **吹き飛んだ後は物理エンジンに任せない:** Rigidbody に力を加えるのではなく、初速と摩擦で自分で動かす
- **基本値は EnemyTuning、銘の倍率は MeiStats:** 2つを掛けて使い、銘の効果を自分で計算しない
- **GameScene を保存するのは三條さんだけ:** 他の2人から配置を頼まれたら、昼の統合のときにまとめて入れる

## 実装の例

```csharp
public class Enemy : MonoBehaviour, ILaunchable
{
    [SerializeField] EnemyTuning tuning;
    float glow;          // 光の蓄積
    Vector3 velocity;
    int slashId = -1;

    public Transform Transform => transform;
    public Vector3 Position => transform.position;
    public float Weight => tuning.weight;
    public float GlowMultiplier => 1f + glow;
    public bool IsShieldFacing(Vector3 slashDir) => false;   // 盾持ちだけ判定する

    public void Launch(Vector3 velocity, int slashId)
    {
        this.velocity = velocity;
        this.slashId = slashId;
        glow += tuning.glowStep * GameContext.MeiStats.GlowGainMultiplier;
        GameEvents.RaiseGlowChanged(this, glow / tuning.maxGlow);
    }

    void FallOff()
    {
        GameEvents.RaiseEnemyFell(new EnemyFellInfo(slashId, transform.position));
        Destroy(gameObject);
    }
}
```
