# 増永さんの連携

増永さんの担当(演出基盤、SE、画面、スコア、銘)のうち、他の2人と関わる所だけをまとめた。受け取るイベントが一番多いので、まず一覧から自分の使い道を探す。

## 受け取るもの

| 流れてくるもの | 誰から | 使い道 |
| --- | --- | --- |
| `SwordPlanted` | 髙橋 | 光の輪、刺さる音、大銘「引力」 |
| `SlashStarted` | 髙橋 | 斬り抜けの音 |
| `EnemyHit` | 髙橋 | 当たりのエフェクト |
| `SlashFinished` | 髙橋 | 納刀の音、大銘「震」「残光」 |
| `ChainChanged` | 髙橋 | 連鎖倍率の表示 |
| `PlayerDamaged` | 髙橋 | 被弾の表現 |
| `GlowChanged` | 三條 | 敵が白く光る |
| `EnemyTeetered` | 三條 | 縁で揺れる |
| `EnemyFell` | 三條 | スコア、一振り最多、光の粒、小銘の候補までのカウント |
| `SwarmCountChanged` | 三條 | 刀の光の揺らぎ |
| `WaveStarted`、`WaveCleared` | 三條 | ウェーブ表示、大銘の候補を出す |
| `GameOver` | 三條 | リザルトへ |

## 渡すもの

| 何を | 誰へ | どう渡すか |
| --- | --- | --- |
| 揺れ、SE、エフェクト | 髙橋、三條 | `Feedback` の中身を作る。2人は呼ぶだけ |
| 銘の最終値 | 髙橋、三條 | `IMeiStats` を実装して `GameContext.MeiStats` に入れる |
| 大銘が変わった | 髙橋 | `GameEvents.RaiseMajorMeiChanged` |
| 「震」「残光」の吹き飛ばし | 三條 | 敵の `Launch` を呼ぶ |

## 気をつけること

- **イベントは OnEnable で登録し、OnDisable で必ず解除する:** 解除し忘れると、シーンを読み直したときに消えたオブジェクトが呼ばれてエラーになる
- **銘の選択画面では時間を止めてもらう:** 開くときに `TimeController.RequestPause(this)`、閉じるときに `ReleasePause(this)` を呼ぶ。`Time.timeScale` は直接触らない
- **UIの動きは unscaled time で書く:** 時間が止まっている間もUIが動くようにする
- **MeiStats は常に「上限で切った最終値」を返す:** 髙橋と三條さんはそのまま使うので、0や未設定にしない
- **「震」「残光」で敵を飛ばすときの slashId:** 直前の `SlashFinished` で届いた番号を使うと、同じ一振りとして数えられる
- **SEとエフェクトのIDは増永さんが足してよい:** `Shared/` の中で、`SeId` と `VfxId` の列挙だけは直接追加してよい

## 実装の例

```csharp
public class ScoreCounter : MonoBehaviour
{
    void OnEnable()  => GameEvents.EnemyFell += OnEnemyFell;
    void OnDisable() => GameEvents.EnemyFell -= OnEnemyFell;

    void OnEnemyFell(EnemyFellInfo info)
    {
        // info.SlashId ごとに数え、一振りの得点と最多を出す
    }
}

public class MeiSelectWindow : MonoBehaviour
{
    public void Open()
    {
        TimeController.RequestPause(this);
        gameObject.SetActive(true);
    }

    public void Close()
    {
        gameObject.SetActive(false);
        TimeController.ReleasePause(this);
    }
}
```
