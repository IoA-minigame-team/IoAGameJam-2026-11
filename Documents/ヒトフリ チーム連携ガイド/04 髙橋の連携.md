# 髙橋の連携

髙橋の担当(主人公、カメラ、時間制御、基盤コード)のうち、他の2人と関わる所。三條さんと増永さんにとっては「髙橋に何を頼めるか」の一覧でもある。

## 受け取るもの

| 何を | 誰から | 使い道 |
| --- | --- | --- |
| `SwarmCountChanged` | 三條 | 自動の斬り戻しまでの時間を縮める |
| `GameContext.MeiStats` | 増永 | 線の幅、吹き飛ばし力、移動速度など主人公の値すべて。大銘「返し」も `HasReturnSlash` で読む |
| `GameOver` | 三條 | 入力を止める |
| `RequestPause` / `ReleasePause` | 増永 | 銘の選択中に時間を止める |

## 渡すもの

| 何を | 誰へ | どう渡すか |
| --- | --- | --- |
| 基盤コード一式 | 全員 | 開発初日に `Scripts/Shared/` に置く |
| 吹き飛ばしの初速 | 三條 | 敵の `Launch` を呼ぶ |
| 主人公の出来事 | 三條、増永 | `SwordPlanted` など主人公側のイベント |
| 時間の制御 | 全員 | `TimeController` |

## 気をつけること

- **初速には敵の重さと蓄積を掛ける:** `Weight` と `GlowMultiplier` を敵から読み、自分では敵の状態を持たない
- **slashId は斬り戻しのたびに新しく採番する:** 斬り抜け中に当たった敵には全員同じ番号を渡す
- **盾持ちに正面から当たっただけなら空振り扱い:** `IsShieldFacing` で判定する
- **基盤コードを変えたら、その日の朝会か夜の試遊で共有する:** 2人のコードが壊れないよう、変更は追加を基本にする
