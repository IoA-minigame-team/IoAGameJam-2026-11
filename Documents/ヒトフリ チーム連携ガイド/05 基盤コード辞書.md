# 基盤コード辞書

3人をつなぐコードの呼び方と、なぜその形にしたかをまとめた。すべて `Scripts/Shared/` にあり、髙橋が開発初日に用意する。ここに書いたシグネチャは目安で、実物はコードのコメントが正しい。

## GameEvents(出来事の知らせ)

**意図:** 他の人のクラスを参照せずに「起きたこと」を伝えるため。static にしてあるので、どこからでも登録と発行ができる。使うのはC#標準の `event` だけ。

```csharp
// 受け取る側(必ず OnEnable で登録、OnDisable で解除)
void OnEnable()  => GameEvents.SwordPlanted += OnSwordPlanted;
void OnDisable() => GameEvents.SwordPlanted -= OnSwordPlanted;
void OnSwordPlanted(Vector3 position) { /* ... */ }

// 流す側(発行は Raise から始まるメソッドで行う)
GameEvents.RaiseSwordPlanted(transform.position);
```

| イベント | 流す人 | 渡す値 |
| --- | --- | --- |
| `SwordPlanted` | 髙橋 | 刀の位置 |
| `SlashStarted` | 髙橋 | slashId、始点、終点 |
| `EnemyHit` | 髙橋 | slashId、敵、初速、正面度 |
| `SlashFinished` | 髙橋 | slashId、当てた数(0なら空振り) |
| `ChainChanged` | 髙橋 | 連鎖数 |
| `PlayerDamaged` | 髙橋 | 残りの被弾回数 |
| `GlowChanged` | 三條 | 敵、蓄積の割合 |
| `EnemyTeetered` | 三條 | 敵 |
| `EnemyFell` | 三條 | slashId、落ちた位置 |
| `SwarmCountChanged` | 三條 | 刀に群がっている数 |
| `WaveStarted`、`WaveCleared` | 三條 | ウェーブ番号 |
| `GameOver` | 三條 | なし |
| `MajorMeiChanged` | 増永 | 新しい大銘 |

`SlashStarted`、`EnemyHit`、`SlashFinished`、`EnemyFell` の値は構造体(`〜Info`)で渡す。

slashId は髙橋が斬り戻しのたびに採番する番号で、「どの一振りで起きたか」を3人で共有するために使う。

## ILaunchable(吹き飛ばせるもの)

**意図:** 髙橋が敵の種類を知らずに吹き飛ばせるようにするため。敵が増えても主人公側のコードは変わらない。

```csharp
public interface ILaunchable
{
    Transform Transform { get; }   // 白く光る、縁で揺れるなどの演出で使う
    Vector3 Position { get; }
    float Weight { get; }          // 盾持ちは重い
    float GlowMultiplier { get; }  // 光の蓄積による倍率
    bool IsShieldFacing(Vector3 slashDir);
    void Launch(Vector3 velocity, int slashId);
}
```

実装するのは三條さん、呼ぶのは髙橋と増永さん(大銘「震」「残光」)。

## IMeiStats と GameContext(銘の最終値)

**意図:** 銘の仕組みを知らなくても、最終的な値だけを読めるようにするため。銘が増えても読む側のコードは変わらない。

```csharp
public interface IMeiStats
{
    float LineWidthMultiplier { get; }
    float LaunchPowerMultiplier { get; }
    float FreeHandSpeedMultiplier { get; }
    float AutoReturnTimeMultiplier { get; }
    float SlashSpeedMultiplier { get; }
    float GlowGainMultiplier { get; }
    float LureRadiusMultiplier { get; }
    int MaxDamageOffset { get; }      // 被弾上限の増減(捨て身で -1)
    bool HasReturnSlash { get; }      // 大銘「返し」
}

// 読む側(基本値は各自の Tuning、銘の倍率を掛ける)
float width = tuning.LineWidth * GameContext.MeiStats.LineWidthMultiplier;
```

実装して `GameContext.MeiStats` に入れるのは増永さん。増永さんの実装ができるまでは、倍率がすべて 1 の `DefaultMeiStats` が入っているので、髙橋と三條さんは待たずに使える。

`GameContext` には主人公と刀の状態も置く。書くのは髙橋で、他の人は読むだけ。
- `PlayerTransform` … 敵が主人公を追うときに使う
- `IsSwordPlanted`、`SwordPosition` … 途中で湧いた敵も刀の状態を知れるようにする
- `AutoReturnRemaining`、`AutoReturnLimit` … 自動で斬り戻すまでの残り秒数と今の制限時間(刺さっていない間はどちらも 0)。残り時間の見せ方で、計算式を持たずに割合を出せるようにする

遊び方も `GameContext` に置く。これだけは書くのが増永さん(タイトル)で、他の人は読むだけ。
- `Mode` … `GameMode.Clear`(全5波で終わる)か `GameMode.Endless`(果てなく)。シーンをまたいで残るので、リトライは同じ遊び方で始まる。再生を始めたときは `Clear` に戻る。ウェーブの終わり、記録の保存先、大銘を出すかどうかの分かれ目に使う

## Feedback(揺れ、SE、エフェクト)

**意図:** 演出の作り方を知らなくても、IDを指定するだけで鳴らせるようにするため。中身が空でも呼べるので、演出の完成を待たずに呼ぶ場所だけ先に書ける。

```csharp
Feedback.Shake(0.2f, 0.1f);
Feedback.PlaySe(SeId.Slash, transform.position);
Feedback.SpawnVfx(VfxId.FallSpark, position, Quaternion.identity);
```

中身を作るのは増永さん。`SeId` と `VfxId` の列挙は増永さんが直接足してよい。

中身は `IFeedbackService` を実装し、OnEnable で `Feedback.Service` に入れる。`SeId` と `VfxId` の項目は末尾に足す。

## TimeController(時間の制御)

**意図:** 時間を止める、遅くする処理がぶつからないようにするため。`Time.timeScale` を書き換えてよいのはこのクラスだけ。

```csharp
TimeController.HitStop(0.08f);          // ヒットストップ
TimeController.Slow(0.3f, 0.5f);        // 倍率、秒数
TimeController.RequestSlow(this, 0.3f); // 長さが前もって決まらないスロー(斬り抜け演出など)
TimeController.ReleaseSlow(this);       // 遅くした本人が解除する
TimeController.RequestPause(this);      // 銘の選択中など
TimeController.ReleasePause(this);      // 止めた本人が解除する
```

| 要求 | 優先度 |
| --- | --- |
| RequestPause(銘の選択中) | 高 |
| HitStop | 中 |
| Slow、RequestSlow | 低 |

止めた本人が解除する形にしているので、2人が同時に止めても、片方が解除しただけでは動き出さない。UIは時間が止まっていても動くよう unscaled time で書く。
