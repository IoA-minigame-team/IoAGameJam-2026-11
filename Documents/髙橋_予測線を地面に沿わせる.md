# 刀の予測線を地面に沿わせる

2026年11月13日。対象: A担当(髙橋)の `Assets/_Project/Scripts/Player/SlashLineView.cs`。

## 起きていたこと

InGame の地面(`GameJamIsland` の `DarkMeadow_Walkable_Ground.001`)は、見た目だけでなく MeshCollider にも凸凹がある。予測線は両端を「足元の高さ + 0.02m」に置いた直線だったので、足元より地面が高い所で線の一部が地面に潜っていた。

## 直したこと

- 中心線と両縁の3本を `Segment Length`(0.25m)ごとの点に区切り、各点から真下に Raycast して、当たった地面の高さ + `Height Offset` に置く
- 3本はそれぞれの位置で地面を取る。縁だけが段差に掛かっても潜らないようにするため
- 主人公も地面と同じ Default レイヤーにいるので、主人公とその子のコライダーに当たった分は捨てる
- 地面が見つからない点(島の端の外など)は、これまでどおり足元の高さに置く

浮かせる量を増やすだけの案は、見下ろしカメラで線が地面からずれて見えるので採らなかった。ZTest Always で手前に描く案は、敵や主人公の体の上にも線が乗るので採らなかった。

## インスペクターの値

`Player` Prefab の SlashLineView に次の値を足した。初期値のままで動くので、Prefab は変えていない。

| 項目 | 初期値 | 意味 |
| --- | --- | --- |
| Ground Mask | Default | 地面として高さを拾うレイヤー。Enemy レイヤーは含めない |
| Segment Length | 0.25m | 線を区切る間隔。短いほど凸凹に細かく沿う |
| Max Point Count | 64 | 1本の線の点の上限 |
| Ray Start Height | 1m | 足元からどれだけ上から地面を探すか |
| Ray Length | 3m | 下向きに地面を探す長さ |

## 他の担当への影響

- 地面のコライダーを別のレイヤーに移すときは、SlashLineView の Ground Mask もそのレイヤーに合わせる(髙橋に伝える)
- 地面に Default レイヤーのコライダー(装飾物など)を置くと、線がその上に乗る。乗せたくない物は別のレイヤーにする
- `Shared/` は変えていない
