# 懸念と検証計画

最大の懸念は「崖っぷちに立つ緊張が、理不尽さに変わらないか」で、開発2日目の終わりにチーム外の人に触ってもらって判定する。

| 懸念 | 主な対策 |
| --- | --- |
| 囲まれると打つ手がない | 手ぶらの移動速度と敵の速さで調整、斬り戻し後の硬直を短くする |
| 縁に立つのが唯一の正解になる | 島の凹凸、湧き場所の切り替え、縁から湧く敵、横に弾いて落とす技 |
| 吹き飛ぶ向きが読めない | 線の幅の縁を地面に描き、真正面ほどまっすぐ飛ぶ単純なルールに保つ |
| 中央の敵が倒せない | 光の蓄積で、当てるほど遠くへ飛ぶようにする |
| 銘で強くなりすぎる | 段階の上限、足し算での重ねがけ、能力ごとの全体上限 |

## 2日目終わりの判定基準

- [ ] 崖っぷちに立つことに、理不尽ではない緊張感があるか
- [ ] 3分遊んでも、毎回同じ動きになっていないか
- [ ] 手ぶらで走っている時間が、退屈ではなく緊張になっているか
- [ ] 当たった位置で飛ぶ向きが変わることに、説明なしで気づくか
- [ ] 5体以上まとめて場外へ落としたとき、気持ちいいか

## 撤退ライン

- **囲まれると何もできない:** 移動速度を上げ、硬直を短くする。それでも駄目なら斬り戻しの終点を少し動かせるようにする
- **毎回同じ動きになる:** 灯喰らいと盾持ちの比率を上げ、湧き場所の切り替えを増やす
- **手ぶらが退屈:** 自動の斬り戻しまでを2秒に縮める
- **吹き飛ぶ向きが読めない:** 横方向への逸れを弱め、ほぼ進行方向に飛ぶようにする
- **中央の敵が残り続ける:** 蓄積を強める。それでも駄目なら一定回数当てた敵は場外でなくても倒れるようにする
- **銘が間に合わない:** 小銘4種と大銘2種に削る。それでも厳しければ小銘だけにする
