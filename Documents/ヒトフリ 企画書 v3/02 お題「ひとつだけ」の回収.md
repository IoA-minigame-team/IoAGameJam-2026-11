# お題「ひとつだけ」の回収

すべての「ひとつ」は「刀が一本しかない」ことから導く。どれかを「ふたつ」にすると遊びが壊れることを、回収の基準にする。

| ひとつだけのもの | ふたつにすると何が壊れるか |
| --- | --- |
| 刀 | 手放しても手元に残り、手ぶらの緊張が消える |
| 斬撃の線 | 「一本の線に並べる」誘導が成り立たない |
| 足場(浮島) | 落ちた先にも足場があれば、場外で倒す意味が消える |
| 光(と色) | 影の集まる先が分散し、刀を餌にする戦略が消える |
| 大銘 | 挙動を重ねられると「どの戦い方を選ぶか」の悩みが消える |
| ボタン | 操作と「手放す」意味が一致しなくなる |

発表用の一言は「刀は一本だけ。突き立てて、離れて、斬り戻す。その一本の線が、群れを島の外へ弾き飛ばす。」
