# 概要

刀は一本だけ。突き立てて、離れて、斬り戻す。その一本の線が群れを島の外へ吹き飛ばす、見下ろし型の3D剣戟アクション。

体験の核は「刀を餌に群れを集め、崖っぷちに立ち、一直線に斬り戻す一瞬で群れをまとめて場外へ弾き飛ばす」こと。敵は斬って倒すのではなく、唯一の足場である浮島から落として倒す。落とすたびに刀へ銘を重ね、毎回違う戦い方が生まれる。

| 項目 | 内容 |
| --- | --- |
| 仮タイトル | 『ヒトフリ』 |
| ジャンル | 3D見下ろし型アクション(ウェーブ制) |
| 操作 | 移動とボタン1つだけ |
| プレイ時間 | 1プレイ約5分(全5ウェーブ) |
| リプレイ性 | 重ねていく銘の組み合わせと、一振りでの最多撃破の記録 |
| 提出 | unityroom(WebGL) |
| 開発体制 | エンジニア3人、開発期間1週間 |
| エンジン | Unity 6.3 LTS、URP |

細かい挙動と数値は『ヒトフリ』仕様書に分けた。この企画書は「何を目指すか」を揃えるためのもので、迷ったときはここに立ち返る。
