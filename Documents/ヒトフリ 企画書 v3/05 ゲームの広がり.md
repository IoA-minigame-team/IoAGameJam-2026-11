# ゲームの広がり

敵、島、銘、記録の4つで、同じ操作から毎回違う一振りを生む。どれも「刺す位置と立つ位置を考えさせる」ために置く。

- **敵:** 主人公を追う「影」、刀に群がる「灯喰らい」、正面を盾で守る「盾持ち」の3種。すべて浮遊する影で、歩行アニメーションは使わない
- **島:** 縁に凹凸のある浮島ひとつ。ウェーブごとに湧き場所を変え、立つべき場所の正解を毎回ずらす
- **銘:** 数値を積み上げる「小銘」は重ねられ、挙動を変える「大銘」はひとつだけ刻める。「積み上げる楽しさ」と「ひとつを選ぶ悩み」を両立する
- **記録:** スコアに加え、一振りで落とした最多の数を主要な記録にする。「もっと長い線で、もっと多く」が挑戦の動機になる
