## なぜ影だけ出ていたか

これまで、新規グループは影のPrefabで始まり、種類の変更にはPrefab参照の手動指定が必要でした。種類をランダムに抽選する機能はありませんでした。

開始時点の `PlayerIntegrationRoutePlan.asset` は、第1波20体・第2波30体の両方が影でした。数を変えても種類は影のままです。この調整内容は上書きしていません。また、区域を広げても、無効な出現ポイントが自動で有効になるわけではありません。

## ツールから種類と出現場所を設定する

1. Playを止め、使いたいシーンを開きます。
2. メニュー **Hitofuri → Sanjo → ステージ・出現管理** を開きます。
3. **ウェーブ設定** で「編集する出現計画」のアセット名を確認します。別の計画を編集している場合は警告が出ます。必要に応じ「この計画を現在のシーンに設定」を押します。
4. 波と出現グループを選びます。
5. 固定なら **影 / 盾持ち / 灯喰らい（人狼モデル）** のボタンを押します。ボタンを押すと、その種類の固定出現に切り替わります。
6. ランダムなら **種類を1体ごとにランダム** をオンにします。最初は3種類が候補に入り、各候補は等確率です。候補を減らせば、選んだ種類だけから抽選します。これは種類の抽選で、3体ごとに必ず3種類が揃う仕組みではありません。
7. 数・遅れ・間隔・出現区域を調整し、**出現計画を保存** を押します。
8. **出現ポイント** で「この点を使う」、区域、座標、周辺半径を設定します。必要なら床合わせを行い、**出現ポイントのシーンを保存** を押します。種類の抽選と位置の選択は別です。位置は有効なポイントと周辺候補から安全な場所を選びます。
9. **接続・引渡し確認 → 現在の接続と出現データを点検** でNGがないか確認してからPlayします。

Play中の計画編集は無効です。停止してから編集してください。

| 計画アセット（すべて `Assets/_Project/Data/Tuning/`） | 用途 |
| --- | --- |
| `EnemyWavePlan.asset` | 通常の5ウェーブ |
| `ThreeEnemyReviewPlan.asset` | 3種類を必ず同時に比較する固定構成 |
| `PlayerIntegrationRoutePlan.asset` | 通し確認用。今回確認した時点では20体・30体の影に調整済み |

3種類を確実に比較したい場合は、ランダム抽選より `ThreeEnemyReviewPlan.asset` の固定構成が適しています。

## 自分で動作を見る

メニュー **Hitofuri → Sanjo → Open Three Enemy Review** から `Assets/_Project/Scenes/Dev/Sanjo/ThreeEnemyReview.unity` を開いてPlayします。

- WASDで移動します。左クリックを押し続けて刀を置き、移動後に離すと斬り戻します。
- 3種類の出現後、近づく様子と自動攻撃を見ます。刀を置くと灯喰らいだけが刀へ向かいます。
- 「正面ガード配置」で盾の正面を試し、背後からの斬り戻しと比較します。
- 柵際ではScene表示で敵Rootと柵の位置も見ます。斬った後に、白さだけでなくRootの位置と傾きが変わることを確認します。柵へ押す方向は柵で止まり、柵から離す方向には飛ぶのが正しい動作です。
- 命中による光の蓄積は残る仕様です。光が残っていても、停止した敵は再び斬り戻しの対象になります。

出現点の保存は、1点だけ座標と有効状態を変更して保存し、別シーンを開いて戻ると確認できます。

## 検証の範囲

`FenceRoundChecks.cs` はEditor専用です。一時シーンでPrefab由来の出現点を保存・再読込し、一時的な床と柵で重なり・接触・上り坂・停止後の実斬り戻し判定を検査します。さらに、メモリ上の計画から実際のWaveControllerとSpawnerで30体を生成し、3種類が出ることと残数の扱いを確認します。既存シーンや調整アセットは保存しません。

通常の吹き飛び、5ウェーブ、実主人公による三種確認もUnity Play Modeで実行しました。検証中断の初動については状態通知をスイートへ直接渡す確認、自動停止と通常Play再開については既存の8検証を使うスイートで確認しました。

| Unityで実行した検証 | 結果 |
| --- | --- |
| 柵、坂、Prefab保存、実斬り戻し判定、ランダム出現、初動の中断通知 | 16項目成功 |
| 既存の吹き飛びと落下 | 43項目成功 |
| 5ウェーブとGameEvents連携 | 46項目成功 |
